# PACOTE DE 3 VÍDEOS — LEIA PRIMEIRO

Este pacote foi montado para o **Codex conectado ao GitHub**, com operação pelo aplicativo de celular.

## Conteúdo

- `COMANDO_MESTRE.md`: projeto, estilo 2D, duração, isolamento, HyperFrames, pipelines, validação.
- `VIDEO_01_OCEANO.md`: 12 cenas completas, narração, direção de arte, física da pressão, áudio e efeitos.
- `VIDEO_03_IMORTALIDADE.md`: 12 cenas completas, consequências sociais de uma hipótese fictícia, direção e som.
- `VIDEO_04_COCEGAS.md`: 12 cenas completas, neurociência e personagens 2D articulados.
- `EXECUTAR_CADA_VIDEO.md`: prompts para rodar os três em sequência **ou cada um isoladamente**.

## Passos no celular

1. Baixe e extraia o arquivo ZIP. Coloque os arquivos `.md` no repositório GitHub que o Codex usa, preferencialmente mantendo a pasta `pacote_3_videos_codex`. Uma alternativa é anexar os `.md` diretamente na sessão, se a interface permitir e o Codex puder ler o anexo.
2. Abra a sessão do Codex conectada ao mesmo repositório e branch.
3. Abra `EXECUTAR_CADA_VIDEO.md`, copie o comando **OPÇÃO A** para solicitar os três vídeos sequencialmente, ou **OPÇÕES B, C e D** para produzir um de cada vez.
4. Peça para o Codex verificar os caminhos e realmente inspecionar a infraestrutura do repositório antes da produção.
5. Ao final, confirme os MP4 e relatórios QA reais. O pacote contém **roteiros e comandos, não contém MP4**.

> Sem a estrutura real do repositório, este pacote não pode garantir que o HyperFrames ou a renderização de áudio/vídeo esteja operacional. Ele exige transparência sobre recursos e resultados, evitando falsas entregas.

**Não produzir o vídeo 02 da respiração** neste pacote.
